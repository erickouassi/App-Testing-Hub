Developer Guidelines

Last updated:

1. Feed Requirements

Your RSS feed must:

  • Be valid XML
  • Contain exactly one <item>
  • Use the AppHub namespaces
  • Include platform, version, status, and testing links
  • Include a valid pubDate

2. Allowed Status Values

  • open-testing
  • closed-testing
  • testing-completed
  • expired
  • not-started
  • internal
  • invite-only
  • marketplace
  • pre-registration

3. Feed Submission

Submit your feed URL via GitHub pull request or email. Once approved, it will be added to feeds.json.

4. Removal Policy

Feeds may be removed if they are invalid, broken, misleading, or violate guidelines.
